# Ve Nguyen Portfolio Website

## Overview

This project is a personal portfolio website created for the CS 463 Final Project.

The website introduces me, highlights my skills, showcases my projects, and provides a way for visitors to contact me.

## Projects Included

### Pokédex Fetch API Project

A JavaScript application that retrieves Pokémon data using Fetch API and displays searchable Pokémon cards.

### ChocAn Healthcare Management System

A Python-based healthcare management application that manages members, providers, services, and reports.

## Installation

Clone the repository:

```bash
git clone git@github.com:venguyen1809/cs463final-project.git
```

Open index.html in a browser.
